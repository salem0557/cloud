# صياد أخطاء الأسعار (أمازون السعودية + أمريكا) — إلكترونيات

يشتغل مجاناً على GitHub Actions كل 5 دقائق ويرسل تنبيه تيليجرام إذا:
- 🚨 منتج أقل من سعره الطبيعي بشكل غير منطقي (مثلاً MacBook Pro أقل من 3000 ريال) = خطأ تسعير محتمل.
- 📉 نزل 55%+ عن متوسط سعره اللي سجله البوت.
- 🔥 خصم 70%+ عن السعر الأصلي المشطوب.
- ♻️ المجدد / Resale بحالة ممتازة: له حد سعر أقل (60% من حد الجديد)، والحالات السيئة (Acceptable/Fair) تُستبعد. الإعداد في `resale` داخل `config.json`.

## التشغيل
1. من **@BotFather** في تيليجرام: `/newbot` وخذ الـ token، وأرسل أي رسالة للبوت الجديد.
2. في GitHub: المستودع ← Settings ← Secrets and variables ← Actions ← New repository secret:
   - `DEALS_BOT_TOKEN` = الـ token
   - `DEALS_CHAT_ID` = رقم محادثتك (إذا ما تعرفه اتركه، أول تشغيل يرسله لك البوت)
3. Actions ← **Amazon price-error hunter** ← Run workflow (تجربة أولى).

## التعديل
كل شي في `config.json`: كلمات البحث، الحدود (`floors`)، نسب الخصم، والكلمات المستبعدة (كفرات، شواحن...).
كل يوم يرسل لك ملخص: كم صفحة فحص، كم تنبيه، وكم مرة حظرت أمازون الطلب.

ملاحظة: أمازون ممكن تلغي الطلب إذا الخطأ واضح جداً. التنبيه يوصلك وأنت تشتري بنفسك.
